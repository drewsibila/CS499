# Software Design and Engineering

## Artifact Overview

For this enhancement, I used my Travlr Getaways project from CS 465.

The original project was a full-stack travel website built with Node.js, Express, Handlebars, MongoDB, and Mongoose. The project included routes, controllers, views, trip data, and database connections.

## Original Artifact

The original version used a local JSON file to store and display trip information.

[Download the Original Travlr Artifact](01_Software_Design_Original_Travlr.zip)

## Enhanced Artifact

For the enhancement, I improved the structure of the application and added stronger database support.

Some of the main improvements included:

- Added a separate MongoDB connection file
- Added a Mongoose schema for trip data
- Added a controller for retrieving trip records
- Added an API route for trip data
- Added a script for loading sample trips into MongoDB
- Improved error handling
- Added an error page
- Better separated the database, controller, routes, and views

[Download the Enhanced Travlr Artifact](02_Software_Design_Enhanced_Travlr.zip)

## What I Learned

One of the biggest things I learned was that a project can work but still have problems with how the code is organized.

Moving the trip data from a local JSON file into MongoDB helped me understand how the database, model, controller, route, and browser all work together.

I also had to fix problems with the database seed data and update older Mongoose code that was no longer working correctly.
